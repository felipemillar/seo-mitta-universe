Anatomía de un Documento Óptimo

Guía definitiva y didáctica para estructurar contenidos orientados a SEO (Buscadores), GEO (Motores Generativos) y AEO (Respuesta Directa de IA).

1. Frontmatter (El Cerebro del Documento)

El "Frontmatter" es el bloque de metadatos oculto al principio de un archivo Markdown. Es el puente de comunicación directo entre tu redacción y el CMS (WordPress, Hugo, Astro).

¿Por qué es vital?
Google no lee el frontmatter directamente, pero tu CMS lo utiliza para inyectar dinámicamente las etiquetas <title> y <meta description> en el HTML final. Si este bloque está mal formateado (por ejemplo, con comillas rotas o saltos de línea incorrectos), la página se indexará con errores graves.

Ejemplo Óptimo:

---
titulo: "Título Atractivo para el Usuario (Se convierte en H1)"
slug: /url-amigable-y-corta/
meta_title: "Título SEO exacto (Max 60 chars)"
meta_description: "Resumen persuasivo con keyword principal que invita al clic (Max 155 chars)."
keywords: [rent a car, arriendo autos, santiago]
categoria: "Rent a Car"
---

Consejo Didáctico: Nunca superes los 60 caracteres en el meta_title ni los 155 en meta_description. Si lo haces, Google truncará tu texto con puntos suspensivos (...), reduciendo drásticamente el CTR (Click-Through Rate).

2. Bloque AEO (La Carnada para IAs)

El AEO (Answer Engine Optimization) es la técnica para ser citado por ChatGPT, Perplexity o los "Google AI Overviews" (los resúmenes de IA que aparecen arriba de las búsquedas).

El Secreto de la IA:
A los Modelos de Lenguaje (LLMs) no les gusta el lenguaje comercial o persuasivo. Están entrenados para extraer "Hechos". Si tu párrafo introductorio dice "¡Descubre la magia de viajar con nosotros al mejor precio!", la IA te ignorará. Si dices "El servicio cuesta $45.000 e incluye seguro.", la IA te citará como fuente de verdad.

La Estructura Correcta:

Coloca este bloque inmediatamente después del título. Responde directamente al Qué, Quién, Cómo, Cuándo o Cuánto.

<!-- AEO-SUMMARY-START -->
> El servicio Drop-Off permite retirar un vehículo en una ciudad y devolverlo en otra. Tiene un costo adicional que depende de la distancia en kilómetros entre sucursales.
<!-- AEO-SUMMARY-END -->

3. Navegación Interna (TOC)

La Tabla de Contenidos (TOC) no es solo para ayudar al usuario a leer; es un mapa jerárquico que los bots utilizan para entender qué tan profundo y completo es tu artículo.

GEO e Indexación:
Google suele generar "Sitelinks" (links adicionales debajo de tu resultado de búsqueda) apuntando directamente a las secciones de tu TOC. Para que esto funcione, cada enlace debe tener un <a href="#id-del-h2"> que coincida exactamente con el id del subtítulo. 
### Tabla de Contenidos
1. <a href="#que-es-el-drop-off">¿Qué es el servicio Drop-Off?</a>
2. <a href="#rutas-populares">Rutas más populares</a>

4. Encabezados y Semántica (H2, H3)

Los encabezados dictan la estructura. Nunca uses un encabezado (H2 o H3) solo porque "quieres que la letra se vea más grande". El tamaño es diseño (CSS); el H2 es estructura semántica.

Conexión con el TOC:
Fíjate cómo el atributo id="que-es-el-drop-off" conecta perfectamente con el enlace de la tabla de contenidos que vimos arriba. 
<h2 id="que-es-el-drop-off">¿Qué es el servicio Drop-Off?</h2>

5. Formateo Nativos GEO (Rompiendo Muros)

A las IAs les cuesta procesar "muros de texto" enormes y densos. Extraen información con mucha más facilidad y precisión cuando los datos están pre-formateados y estructurados visualmente.

  • Tablas: Úsalas para precios, distancias, comparativas (SUV vs Sedán).
  • Listas Numeradas: Úsalas para "Paso a paso" o guías de instrucción.
  • Listas con Viñetas: Úsalas para características, checklists o requisitos.
Impacto en Perplexity/ChatGPT:
Cuando un usuario pide a Perplexity: "Compárame tarifas de arriendo". Perplexity buscará sitios web que tengan tablas HTML/Markdown. Si tienes la información en una tabla, la IA literalmente "copiará" tu tabla y pondrá tu sitio como la referencia [1].

6. Cross-Linking (El Flujo del Link Juice)

Los enlaces internos son como "venas" por las que fluye la autoridad de tu dominio. Si una página no tiene enlaces hacia otras, ni recibe enlaces, se convierte en una "Página Huérfana" (invisible para Google).

El Anchor Text:
El texto donde haces clic es clave. Jamás uses "haz clic aquí". Si el link va a la página de seguros, el texto debe decir "Seguros y coberturas para tu arriendo". Esto le da contexto semántico al bot. 
[LINK INTERNO SUGERIDO: "Revisa nuestra guía de precios actualizados" -> /precio-arriendo-2026/]

7. Schema JSON-LD (El "Cheat Code" SEO)

El Schema Markup es un código invisible para el usuario, pero es el idioma nativo de Google. En lugar de hacer que Google lea el texto e "intente adivinar" de qué trata tu página, el Schema le entrega los datos en bandeja de plata.

El secreto del @graph:
Muchas páginas tienen múltiples schemas (Artículo, FAQs, Breadcrumbs) esparcidos por el HTML, lo que confunde a Google. La mejor práctica absoluta es envolverlos todos dentro de un único array llamado @graph. Esto le dice a Google: "Todo esto pertenece a una misma entidad estructurada".

Plantilla Maestra @graph:

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "Article",
      "headline": "Título del Artículo",
      "inLanguage": "es-CL",
      "image": "https://mitta.cl/imagen.jpg"
    },
    {
      "@type": "FAQPage",
      "mainEntity": [
        {
          "@type": "Question",
          "name": "¿Pregunta frecuente?",
          "acceptedAnswer": {
            "@type": "Answer",
            "text": "Respuesta clara."
          }
        }
      ]
    },
    {
      "@type": "BreadcrumbList",
      "itemListElement": [
        {
          "@type": "ListItem",
          "position": 1,
          "name": "Inicio",
          "item": "https://mitta.cl/"
        }
      ]
    }
  ]
}
</script>
